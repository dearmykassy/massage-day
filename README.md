# 마사지데이

마사지데이는 Template6 화면 구조와 1,291개 지역 그래프를 사용하는 Next.js 16 정적 웹사이트 프로젝트입니다.

운영 사이트는 [msgday.kr](https://msgday.kr)이며 canonical·sitemap·RSS·구조화 데이터는 이 HTTPS origin을 사용합니다.

## 공개 문서 계약

- 지역 경로는 정본 그래프의 1,291개만 사용합니다. 광역 41개 페이지는 11개, 세부 1,250개 페이지는 10개의 서비스 중심 본문 섹션을 가지며 하위·형제·상위 지역 디렉터리를 마지막에 둡니다.
- 홈·전체 지역 카드와 광역 41개 페이지의 고객 노출 지역명은 `서울`, `인천`, `경기`, `수원`처럼 행정 접미사를 덜어 표시합니다. URL·canonical·정본 행정 그래프는 그대로 두고 세부 구·동 페이지의 이름은 유지합니다.
- 각 지역의 primary keyword는 공백을 포함한 `<고객 검색형 지역명> 출장마사지`입니다. SEO title 앞부분, `primary keyword + 방문관리 서비스 안내` 단일 H1, 첫 100어절, 서비스 소개와 서로 다른 H2 두 곳에 자연스럽게 배치합니다. H1은 raw 1,291개 고유성과 대표어 1회를 검사하며, 고객에게 의미 없는 문형 순환은 사용하지 않습니다.
- 공통 운영 사실은 자연스러운 공통 문장으로 재사용하고 지역명을 붙여 문단만 고유하게 만들지 않습니다. 지역명으로 시작하는 hook·본문 문장은 페이지당 4–8개만 허용하며, meta description은 70–180자로 제한합니다. 화면 장식에는 route depth·ordinal 같은 내부 구조 값을 노출하지 않습니다.
- 지역 본문은 서비스 소개, 실제 지역 범위, 전화 예약 문의 준비, 5개 코스 요약, 2인 프로그램, 현장 후불, 비품·소독, 이용 흐름을 설명합니다. 전체 14개 가격 행과 공통 FAQ는 반복하지 않고 `/pricing/`, `/guide/`의 실제 링크로 연결합니다.
- 하위 지역이 없는 말단 페이지는 같은 상위 단계의 실제 형제 지역을 관련 링크로 제공합니다. breadcrumb·상위 이동·하위 또는 형제 링크를 합쳐 모든 지역 페이지에 self가 아닌 문맥 지역 링크를 최소 3개 유지합니다.
- 각 페이지는 상위·하위·형제·별칭·법정명 관계에서 확인한 지역 사실 문단을 최소 3개 렌더합니다. 현재 target과 브랜드만 중립화한 전체 본문과 지역 사실 signature는 1,291개 모두 충돌이 없어야 하며, 지역 사실 문단은 본문 문단 문자의 25% 이상을 유지합니다.
- 모든 고정·블로그·지역 페이지는 고유한 title, keywords, description과 self canonical, Open Graph, Twitter 메타를 제공합니다.
- 지역 구조화 데이터는 사실 기반 `WebPage`와 화면 경로를 그대로 옮긴 `BreadcrumbList`만 발행합니다.
- sitemap은 고정 페이지 6개, 블로그 글 2개, 지역 페이지 1,291개를 합친 1,299개 URL을 담습니다.
- RSS 2.0은 실제 게시일과 영구 GUID를 가진 블로그 글 2개의 전체 본문만 제공합니다. 지역 URL 목록은 sitemap에서 관리합니다.
- canonical·sitemap·RSS는 `https://msgday.kr`을 사용하고 모든 공개 페이지는 `index,follow`, robots는 전체 허용 상태입니다.

## 이미지 계약

- 지역 배너는 승인된 마스터 216장으로 1,291개 경로를 구성합니다. 기존 승인본 72장과 마사지데이 신규 생성본 144장을 사용하며 원본 한 장의 최대 재사용은 6개 경로입니다.
- 최종 재사용 구성은 필링홈타이 24장, 건마에반하다 24장, 혼혈마사지 24장입니다. 원본 플랫폼의 승인·릴리스 해시와 마사지데이 복사본 해시를 provenance에 보존합니다.
- 반응형 지역 파생물은 데스크톱 1,600×900, 태블릿 1,200×675, 모바일 768×600의 WebP 648개입니다. 홈 지역 카드 11개와 홈·블로그 배너 3개도 별도로 릴리스합니다.
- 광역·시 상세 41개 경로는 모두 신규 이미지입니다. 전체 배정에서 부모·자식 및 같은 부모의 형제 이미지 충돌은 0건입니다.

## 개발과 검증

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm audit:copy
pnpm typecheck
pnpm lint
pnpm build
pnpm audit:build
```

`pnpm audit:copy`는 `os.homedir()/Documents`에서 지정된 기존 플랫폼 7개를 모두 확인한 뒤 실행됩니다. 외부 exact·브랜드/지역 중립화 충돌, 내부 raw·target 중립화 전체 본문 충돌, 지역 사실 signature, 문맥 링크, 한국어 조사, 기술·순서·해시 출력 문구를 fail-closed로 검사합니다. 공통 H1·H2·액션·짧은 검증 운영 사실은 허용 공통 signature로 별도 기록하고, 고객 가치 없는 문형 회전을 유도하던 normalized H1 문형 수·문단 slot 재사용 상한은 hard gate에서 제외합니다. 모든 관련 지역명을 제거한 strong Jaccard·exact과 전체 block 반복률은 자연성 추세를 보는 진단 수치로만 남깁니다.

운영 배포에는 마사지데이 전용 GA4 측정 ID를 연결하고 운영 HTML에서 활성화를 확인해야 합니다. 네이버 서치어드바이저에는 sitemap과 RSS를 제출하고 수집 주기를 `빠르게`로 설정합니다.
